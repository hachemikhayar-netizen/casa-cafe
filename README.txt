# CASA CAFÉ Website

A responsive static website for CASA CAFÉ in Nouakchott.

## Files
- `index.html` — website structure and content
- `style.css` — design and responsive layout
- `script.js` — mobile menu and current year
- `images/` — place your restaurant photos here

## Important
The menu items and location text are placeholders based on the information supplied for the website brief. Replace them with the restaurant's confirmed menu, prices, exact address, and real photos before publishing.

## Free publishing
The easiest route is GitHub Pages:
1. Create a GitHub account.
2. Create a new public repository, for example `casa-cafe`.
3. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
4. Open the repository's Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the main branch and the `/ (root)` folder, then Save.
7. GitHub will provide the public website address.

You can later connect a custom domain if desired.
